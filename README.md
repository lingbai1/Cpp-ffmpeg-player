# Player - 基于 C++ 和 FFmpeg 的多线程视频播放器

这是一个使用 FFmpeg 和 SDL2 开发的本地音视频播放器。项目实现了完整的音视频处理管线：包括流文件解封装、音视频多线程独立解码、音频重采样、音画同步以及画面渲染。

## 开发环境

- CMake >= 3.5
- 编译器：支持 C++11 (g++ / clang++)
- 核心依赖：FFmpeg (libavformat, libavcodec, libavutil, libswscale, libswresample)
- 渲染依赖：SDL2

## 编译与构建

推荐使用外部构建：

```bash
mkdir -p build && cd build
cmake ..
make
```

## 运行方式

```bash
./player <输入视频文件路径>

# 运行示例:
./player ../Mytest.mp4
```

### 操作控制

- **空格键:** 暂停 / 恢复播放
- **左/右方向键:** 快退 / 快进 10s
- **鼠标拖拽:** 点击或拖拽底部进度条可进行精确时间跳转 (Seek)
- **窗口调整:** 支持随意拉伸窗口，画面会自动维持原有宽高比并居中显示（黑边填充）。

## 核心实现与技术点

- **多线程架构:** 
  使用 `std::thread` 将解封装 (Demux)、视频解码、音频解码分离为独立的线程；SDL 回调负责最终的音频输出，主控循环处理系统事件监听与画面渲染，结构清晰。
- **线程同步与缓冲队列:** 
  基于 `std::mutex` 与 `std::condition_variable` 实现针对 Packet 和 PCM 数据的跨线程缓冲队列，并设定了最大缓存阈值来限制内存增长。
- **音画同步 (A/V Sync):** 
  以音频播放进度为主时间基准（Master Clock）。在视频渲染阶段，通过比对视频帧 PTS 与音频时钟的差值，动态利用 `SDL_Delay` 控制延迟，或在差异过大时实施丢帧策略，保持声画同步。
- **重采样与像素转换:** 
  利用 `SwrContext` 将格式各异的输入音频统一重采样为 SDL 对应的播放格式；利用 `sws_scale` 即时缩放并将视频数据转为 YUV420P 交由 SDL 底层渲染。
- **资源管理与稳定性:** 
  处理进度跳转 (Seek) 时加入了 Flush 机制，及时清空编解码器缓冲及线程队列。依托良好的生命周期控制，播放器在 1080P 软件解码环境下长期运行稳定，内存占用保持在 188MB 左右，CPU 开销约 14%。
